## Question

hikyuu multifactor 作为系统级能力的接入方式：

1. 因子计算/合成（MF_* 权重/等权/IC/ICIR）、归一化（5 种）、打分过滤（TopN 等）的 CLI/notebook 封装
2. IC/ICIR 分析与分层回测的交互形态
3. 组合路径（SE_MultiFactor2 → SCFilter → AF_EqualWeight → PF_Simple 月度调仓）与第一闭环策略的关系
4. 依赖 T4 的财务因子决策（如启用）

产出：因子研究流水线接入方案。第二闭环。

## Resolution（2026-08-16，grilling）

### 研究资产管理（Q14/Q15/Q16 + 命名）

- **两层资产**：`factors/` 因子库（含信号型因子）+ `strategies/` 策略库（单标的择时与截面组合两种组装形态）；信号不单列成层（截面场景信号=打分选股，择时信号=信号型因子）。
- **纯代码形态**：因子 = `factors/` 下函数返回 `hku.Factor(name, indicator, brief=...)`（复用 hikyuu 因子框架对象，元数据内建）；策略 = `strategies/` 下 build 函数（hikyuu 组件代码组装）。`factors/__init__.py` 扫描注册为 dict。**不做声明式 spec**（单人项目 spec 翻译层收益小，复杂因子终归是代码）。
- **版本与复现**：代码/因子在 git 里（commit hash 即版本）；每次回测把「参数快照 + git commit hash + 指标摘要」写入实验注册表（SQLite）。
- **模块命名**：统一执行器 `backtest.py`（组合回测；单标的=股票池 1 个标的的特例，hikyuu 组合范式内部为每标的建 System 跑信号，架构支持）；因子评估执行器 `run_factor.py`。

### 组合流水线（Q3/Q6/Q11/Q17/Q18/Q19）

- 组件链：`MF_EqualWeight → NORM_Zscore(out_extreme=True) → SE_MultiFactor2 → SCFilter(TopN) → AF_EqualWeight → PF_Simple`。
- 股票池：全市场 9700 只 + 过滤（剔除 ST/*ST、上市不满 60 个交易日、近 20 日零成交即长期停牌），全部参数化（--exclude-st / --min-listed-days / --min-active-days）。
- 因子池第一版（5 个技术因子）：20 日动量、5 日反转、20 日波动率（STD）、**20 日量比**、MA 偏离度（CLOSE/MA20-1）。
  （执行修订 2026-08-16：原定「换手率」不可用——hikyuu TURNOVER/HSL 依赖流通股本（stkfinance 表，当前为空返回 NaN），改用纯价量的 20 日量比 VOL/MA(VOL,20)-1 表达活跃度）
- 合成：默认 MF_EqualWeight（验收口径）；MF_ICIRWeight 作为 `--mf icir-weight` 可选项，评估报告对比两者。
- 归一化：默认 NORM_Zscore(out_extreme=True)，CLI 可切。
- 选股：**TopN 默认 10**（`--topn` 参数化）；SCFilter_IgnoreNan 恒挂。
- 调仓：`adjust_cycle=1 + delay_to_trading_day=True`（每月首个交易日），`--adjust-cycle` 参数化。
- 交易假设：沿用第一闭环（100 万 + TC_FixedA2017 + SP_FixedPercent(0.001)），`--init-cash` 参数化。

### CLI 与实验管理（Q1/Q2/Q12/Q13 + 运行 config）

- **命令族**：`check / backtest（统一，--strategy 选策略）/ factor（因子评估）/ report`。**删除 first-loop 命令**（回归改用 `backtest -c experiments/ma_cross.yaml`）。
- **experiments/ 目录**：每次实验一个 YAML（strategy/topn/mf/norm/股票池过滤/区间/资金/成本），进 git；`backtest -c <path>` 一键执行，参数优先级 CLI 显式 > config 文件 > 默认值；`--report` 自动接报告。
- **实验注册表**：SQLite 单表（run_id/参数快照/commit hash/指标摘要/产物路径）；产物目录 `reports/<YYYYMMDD>_<策略slug>_<关键参数>_<run_id前6位>/` 平铺可读。
- **报告结构**：模式无关升级（meta 加 mode 字段；trades 统一成交明细；组合模式多「调仓明细」区块：调仓日/入选标的/权重变化）；53 项/夏普/回撤/资金曲线复用（PF 内部走 TradeManager，结果同源）。

### 因子评估（Q10）

- `factor` 命令出独立 html 评估报告：IC 序列图 + IC 均值/ICIR/正 IC 占比表 + 分层累计收益图 + 各层年化表。
- 分层用 **SCFilter_Group 10 层**；IC 计算用 hikyuu `mf.get_ic/get_icir`（spearman=True）。
- 因子评估股票池 = 回测同池（同过滤规则）。

### 与第一闭环的关系（Q5/Q21 迁移清单）

- **演进替换**：组合成为唯一回测形态，单标的 MA 金叉退化为「股票池=[sh000001] + 择时 SG」的特例（Q5 B）。
- 迁移清单：① `strategy.py` → `strategies/ma_cross.py`（组合范式表达）；② 旧单标的路径被统一执行器吸收；③ 报告层/JSON 模式无关升级（旧字段兼容）；④ 迁移后验收逐位一致；⑤ factors/strategies/experiments/ 建立，5 因子 + 1 组合策略（ma_mom_top20）为第一批资产。

### 第二闭环验收标准（Q20，七条）

1. `backtest -c experiments/ma_cross.yaml` 数字与第一闭环基线逐位一致（夏普 -0.2224 / 回撤 34.69% / 60 笔交易）——迁移验证
2. `factor` 命令出因子评估报告（IC 序列 + ICIR + 10 层分层收益）
3. 组合策略回测跑通：调仓事件 > 0、持仓数 ≤ TopN
4. 报告数字与 hikyuu Performance 对象一致
5. 固定日期重跑两遍逐位一致
6. 实验注册表有本次运行记录（参数快照 + commit hash）
7. T+1 声明与一字板/停牌处理说明在报告与文档中显式标注

### 明确不做

财务因子（第一版不启用；T4 方案备好，客户端下载专业财务数据后按落库快照+PIT 接入）、notebook 交互形态、spec 声明式资产、分钟级数据。

### 执行修订（2026-08-16，开发实测）

- 组合原型系统 MM 用 **MM_FixedPercent(0.99)**（AF 等权分配资金全额买入会因成本溢出被拒，实测大量 Can't buy，与第一闭环 MM 修订同源）。
- 股票池过滤加**代码前缀白名单**（SH 60/68、SZ 00/30）：hikyuu Stock.type 判定不可靠（板块指数 881 等也会判为 type 1，实测混入股票池抬高了组合收益假象，净化后股票池 2583 只）。
