## Question

报告层 = Performance 44 项（原生）+ 自算指标 + html 汇总：

1. 自算指标方案：夏普比率、资金曲线最大回撤（hikyuu Performance 缺失，从 TradeManager 资金曲线算）的算法与落点
2. html 汇总层形态：模板（jinja2?）、图表（matplotlib/echarts 嵌入）、目录结构（单报告文件 vs 报告目录）、CLI 一键出
3. 绘图选型：matplotlib vs echarts（hikyuu 三引擎绘图的能力边界）

产出：报告层设计。关闭后 T7 可引用。

## Resolution（2026-08-14，grilling）

> 事实基准：Performance 实测 **53 项**（ticket 开票时「44 项」为过时数字，以 53 项为准）；53 项**不含夏普与最大回撤**，须自算。

### 自算指标（算法与落点）

- **年化夏普**：`get_funds_curve(dates, 'DAY')` 总资产日序列 → 日收益率 → `mean/std × √252`，无风险利率 0。落点 `report.py` 纯函数 `calc_sharpe(daily_returns)`，可单测。
- **最大回撤**：hikyuu 原生 `MDD` 指标对资金曲线序列计算 + **自实现算法交叉验证**（执行修订 2026-08-14：原定 `TradeManager.get_max_pull_back()` 在 2.8.1 **恒返回 0.0** 不可用——实测指数/个股、多日期、账户有 28% 回撤时均如此，tmreport 插件问题；交叉验证改为 `report.py` 纯函数 `calc_max_drawdown(equity_values)` 自实现峰值回撤与 MDD 指标末值比对，两值一致才通过）；MDD 序列同时供回撤曲线图。
- **不加第三个自算指标**：年化收益/胜率/盈亏比/交易次数取自 53 项对应条目（帐户平均年收益率%、赢利交易比例%、平均赢利/平均亏损比例、已平仓交易总数——key 名以 2.8.1 `Performance.names()` 实测为准）。

### html 汇总层

- **模板**：jinja2（已装），模板文件 `strategy_research/report/template.html`；数据与模板分离。
- **结构**：**单 html 文件自包含**（图表 base64 PNG 内嵌，双击离线即看）。
- **输出**：`strategy_research/reports/first_loop_report.html`（固定名，重跑覆盖，T1 可复现验收）；`report` 子命令支持 `--output` 指定路径。

### 绘图选型

- **matplotlib（hikyuu 原生引擎，默认）**：资金曲线图用 hikyuu 绩效绘图 `tm.performance(query, ref_stk=sh000001)`（2.8.1 实际形态：`hikyuu.draw.drawplot` 将 matplotlib 实现绑定为 `TradeManager.performance` 方法，顶层 `tm_performance` 函数已不存在；图含收益曲线 + 基准 + 统计文本，**不含回撤子图**——回撤曲线由 MDD 序列补独立小图，见下方布局区块 4），报告层 savefig → base64。
- echarts 引擎本轮不用（2.8.1 缺陷：`per.report()` 带参调用 TypeError；无 TM 绩效绘图）；bokeh 不用（无绩效绘图）。
- **引擎可插拔**：report.py 内 render 函数接口统一，T7 需交互图时再评估 pyecharts，不焊死。

### 报告内容布局（html 区块，从上到下）

1. 头部：策略名/标的/回测区间/交易假设（资金/成本/滑点/成交价模型）+ **T+1 偏差显式声明**（T1 验收条目 7）
2. 核心指标卡 ×6：年化收益、夏普、最大回撤、胜率、盈亏比、交易次数
3. 资金曲线图：策略 vs sh000001 买入持有基准（归一化对比）
4. 回撤曲线图（tm_performance 未含则用 MDD 序列补独立小图）
5. Performance 53 项完整统计表
6. 交易明细表（买卖日期/价格/数量/盈亏）

### 落地约束（执行会话，事实已探明）

- **`crtTM(date=, init_cash=, cost_func=, name=)` 是 2.8.1 唯一正确的 TM 构造方式**（旧 4 参构造已废）。
- **import hikyuu 之前**先 `matplotlib.use('Agg')`（无 GUI 出 PNG 必需；中文字体 hikyuu 自动处理）。
- `get_funds_curve` 2.8.1 签名须传 dates：`tm.get_funds_curve(datetime_list, 'DAY') -> list[float]`（无参调用为旧版 API）。
- **DATE 型 Query 的 end 边界为 exclusive**（执行实测：end=2026-08-13 得最后根 08-12；内部 +1 天处理，见 backtest.py）。
- 自算指标函数须可单测（回撤边角 case：空仓段、单日暴跌）。
- 验收对勾：自算回撤（calc_max_drawdown）与 MDD 指标一致；夏普口径符合 T1 定稿。
