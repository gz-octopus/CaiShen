## Question

「第一闭环」= 数据→因子→策略→回测→报告 的最小通路。本 ticket 解析：

1. 闭环包含哪些具体环节？（数据就绪 → 第一个因子 → 第一个策略 → 一次回测 → 一份报告）
2. 第一个策略长什么样？（建议：hikyuu 原生 Python + 组件体系写一个简单策略，如 MA 金叉择时或 TopN 选股组合；数据全部来自客户端直读 + tqcenter 直取，不落库）
3. 验收物是什么？（CLI 一键出报告的完整链路可复现）
4. 明确不做：公式翻译器、财务因子、多源、交易通道。

产出：第一闭环的内容清单与验收标准。关闭后解锁 T3/T4/T5/T6/T7。

## Resolution（2026-08-14，grilling）

### 第一闭环内容清单（数据 → 因子 → 策略 → 回测 → 报告）

**环节 1 · 数据就绪**（链路 T2 已定稿，此处只定验收口径）
- 日线直读：TdxKDataDriver 直读 `D:\TDX\vipdoc`（9700 只，2020-01-02 起）；权息：`getdividfactors` → stkWeight（唯一落库）。
- 复权口径：**FORWARD（前复权）**。
- **强制就绪校验（两项，任一不过拒绝回测）**：① `tdxw.exe` 进程在；② 权息表非空 + 抽样 3~5 只 `get_weight()` 条数/最近权息日比对。**不校验**日线尾部日期（用户决定，剔除原推荐第 3 项）。

**环节 2 · 因子**
- `hku.indicator.MA(10)` / `MA(30)` + `hku.SG_Cross`（金叉买/死叉卖）。参数固定，不调参。

**环节 3 · 策略**
- **单标的 MA 金叉择时**：sh000001 上证指数，空仓起步、全仓进出、无止损止盈。
- 资金管理落地：**`MM_FixedPercent(0.99)`**（执行修订 2026-08-14：hikyuu 2.8.1 实测 `p=1.0` 时买入金额+交易成本超现金被 TradeManager 直接拒绝——指数 30 次金叉仅 19 次买进、个股 100% 失败；`p=0.99` 留 1% 成本缓冲，30 次全部成交且无警告。0.99 即「全仓进出」的落地形态）
- 交易假设：初始资金 **100 万**；`TC_FixedA2017` + `SP_FixedPercent(0.001)`；**信号次日开盘价成交**（System 默认 `buy_delay/sell_delay=true`，原生行为）。
- A 股规则：**一字板延迟（System 默认）+ 停牌自然跳过**；不做价格钳制、不做 T+1 MM——**T+1 缺失记为已知偏差**，报告与文档显式标注。

**环节 4 · 回测**
- hikyuu 事件驱动（System + TradeManager），区间 **2020-01-02 ~ 2026-08-13**（全量可用数据）。
- 组合路径（multifactor→Portfolio）**不在**本闭环——留给 T7。

**环节 5 · 报告**
- 内容：Performance **53 项**（hikyuu 2.8.1 实测；修正地图 Destination「44 项」的过时表述）+ 自算年化夏普（日收益 ×√252，无风险利率 0）+ 最大回撤（`TradeManager.get_max_pull_back`）+ html 汇总。
- html 最小内容：资金曲线图 + 53 项统计表 + 夏普/最大回撤 + 交易明细表。
- 入口：独立脚本 `python first_loop.py` 一键完成 校验 → 回测 → 报告（固定输出 `reports/first_loop_report.html`）；正式 CLI 形态由 T3 设计并收纳。

### 验收标准（逐条 checklist）

1. 一条命令 `python first_loop.py` 可复现完整链路：就绪校验 → 回测 → html 报告。
2. 就绪校验两项通过（tdxw 进程在；权息非空 + 抽样比对一致）。
3. 交易次数 > 0。
4. 资金曲线可渲染、无异常跳变（重点核对权息生效日曲线连续——复权正确性的直接证据）。
5. 报告数字与 Performance 对象输出一致。
6. **可复现**：固定日期重跑两遍，报告统计数字逐位一致（文件时间戳除外）。
7. T+1 缺失在报告与文档中显式标注为已知偏差。

### 明确不做

公式翻译器（T6）、财务因子、多源、交易通道、参数优化/调参、分钟线、板块数据、T+1 MM、quant_lab 一切。

T3 / T4 / T5 / T6 解除 T1 阻塞，可认领；T7 仍待 T5。
