## Question

研究资产的版本管理方案（2026-08-17 用户提出）：

实验记录表当前只记参数快照——**因子/策略的定义变更（改公式、改组装逻辑、改元数据）无法追溯**。改因子公式后，历史回测用旧公式跑出的数字对不上新公式，而记录里无从分辨。需要定：

1. **版本粒度**：改什么算新版本？（公式实现 / 元数据方向 / 参数默认值 / 名称）
2. **版本表达**：代码侧怎么表达版本？（因子名加版本后缀 v2 / 登记表加 version 字段 / 语义化版本）
3. **实验关联**：实验记录如何关联资产版本？（跑实验时快照因子定义全文 vs 引用版本号 vs 两者结合）
4. **与 git 的分工**：git 已管代码历史，资产版本与 git 版本的关系（资产版本是 git 之上的研究语义层？）

产出：因子/策略版本管理方案。关闭后实验记录表与资产登记同步升级。
