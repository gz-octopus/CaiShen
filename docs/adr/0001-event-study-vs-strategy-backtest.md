# ADR-0001：因子事件研究 vs 策略回测的边界与使用时机

- 状态：已共识（2026-08-18，grilling 设计会话确认）
- 背景：讨论「涨停倍量阴」买入时机测试路径时，明确了因子事件研究与策略回测的分工规则

## 决策

1. **两层以「有无净值路径」为结构性判据划分**：
   - **因子事件研究**（`strategy_research/run_event.py`）：截面统计——事件池化独立计数、等权、无资金、无费用；结果 = 事件的条件期望，无路径依赖。回答「信号平均每笔赚多少」。
   - **策略回测**（`strategy_research/backtest.py` + `strategies/`）：时间序列模拟——资金、仓位、顺序、路径依赖。回答「按此信号交易，账户曲线长什么样」。
   - 判据不是结果数值的接近程度（等权零费用的策略回测与事件研究数值必然接近），而是模型结构。
2. **时机/参数敏感性测试属于事件研究的参数化扩展**，不走策略层；策略层是验证层，不是探索层。含条件成交类入场规则（尾盘、低吸）——日线 OHLC 即可验证（触及条件 + 限价成交），无需分钟数据。

## 使用时机

1. 信号有无信息、哪个参数好、时机敏感性 → **事件研究**（便宜、可归因：冻结一切只变一维）。
2. 净值、回撤、夏普、容量 → **策略回测**（只有它有净值路径）。
3. **升级判据用数据不用感觉**：事件研究报告携带每日事件数分布 + 不可成交剔除比例。两者都小 → 两层必然收敛，策略层无信息增量，可跳过；任一大 → 必跑策略层。
4. **硬触发：上实盘/仿真前必跑策略回测**（真实费用、滑点、涨跌停延迟撮合）。事件研究的结论是「信号有信息量」，不是「可以交易」。

## 执行假设口径（现状）

- 事件研究：事件池化、等权、无费用；买端剔除 D+1 一字板（`run_event.py:146`）；基准 = 同事件日全池等权 + 上证指数。
- 策略回测：T+1 声明（`backtest.py:29-36`）；`TC_FixedA2017` + `SP_FixedPercent(0.001)`。
