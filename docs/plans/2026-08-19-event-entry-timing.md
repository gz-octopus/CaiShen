# 涨停倍量阴事件研究入场时机参数化 — 实施计划与变更说明

- 日期：2026-08-19
- 状态：已实施、已验证（单测 + 冒烟测试通过）
- 关联：`docs/adr/0001-event-study-vs-strategy-backtest.md`（边界与使用时机共识）

## 一、背景与目标

`limitup_vol2_yin`（涨停倍量阴：前日收盘封板 + 当日量 ≥ 前日 2 倍 + 当日收阴）此前的事件研究入口硬编码为「D+1 开盘买入 → D+n 收盘卖出」，无任何入场参数。

目标：把入场时点做成参数，对比不同买入时机对事件后收益的影响，回答「尾盘买 / 次日开盘买 / 次日收盘买 / 次日低吸哪个更好」。按 ADR-0001 规则，此测试属于因子事件研究的参数化扩展，不走策略层。

## 二、决策共识（grilling 设计会话，2026-08-18）

| 决策 | 内容 |
|---|---|
| 路径 | 改因子事件研究（`run_event.py`），不跑策略层；附预警统计（每日事件数分布） |
| 入场变体 | `d1_open`（D+1 开盘基线）/ `d_close`（D 收盘尾盘）/ `d1_close`（D+1 收盘）/ `d1_dip`（D+1 低吸） |
| 窗口语义 | **n = 买入日后第 n 个交易日收盘卖出**（= 持有 n 日），窗口 [1,3,5,10,20]，全变体 T+1 合规（修正旧口径 n=1 同日回转违规，即 G5） |
| 卖端剔除 | 卖出日收盘 = 跌停价 → 剔除样本（G1，与买端一字板剔除对称） |
| 低吸规则 | 参考 K 线 = 涨停 K 线（D-1），中间价 = 实体中分 (open+close)/2；条件 = D+1 盘中 low ≤ 中分价；成交价 = min(D+1 开盘, 中分价) |
| 低吸报告 | 未触及事件剔除 + 报告低吸成交率 + 触及/未触及两组对照（未触及按 d1_open 口径模拟） |
| 尾盘假设 | 信号收盘才严格确认，「D 收盘买入」为理想化近似，报告内标注 look-ahead |
| 基准 | 同事件日、同窗口、同口径入场全池等权；sh000001 同口径叠加 |

## 三、实施方案（实施前批准版，2026-08-18）

1. `run_event.py`：常量区加 `ENTRIES`/`ENTRY_LABELS`/`DIP_REF_SHIFT`；新增纯函数 `_entry_fill`（入场价+有效掩码+低吸触及）、`_fwd_ret`（含卖端跌停剔除）、`_pool_fwd_ret`（基准矩阵）；`study_events` 按变体循环出统计/曲线/年度/低吸附加；`_down_limit_price` 镜像 `_limit_price`；overview 加每日事件数分布。
2. `run_factor.py`：`run_factor` 加 `entries` 参数，bool 路径加建 low 矩阵并透传。
3. `__main__.py`：factor 命令加 `--entries/-e`（`click.Choice`，多选，默认 `d1_open`）。
4. `event_template.html`：按变体分节渲染；窗口统计表/低吸成交率对照表/CAR 曲线/年度分面；「累计净值」改「平均累计收益曲线（CAR）」+ footer 标注。
5. 单测：窗口语义、卖端剔除、低吸三情形（触及/未触及/开盘跳空）、池矩阵、跌停价、非法变体。
6. 附带：模糊点①（模板标注，随 4 一起）、G1/G3/G5；模糊点③核实（只读）；模糊点②（策略层 value_type 过滤）与 G4（费用敏感版）独立后置。

## 五、验证结果

- 单元测试：**43/43 通过**（`_selfcheck/test_strategy_research.py`）。
- 冒烟测试：`python -m strategy_research factor -f limitup_vol2_yin -e d1_open -e d_close -e d1_close -e d1_dip`，exit 0。
- 样本：2583 只 × 2020-01 ~ 2026-08，事件 9114 个。有效样本：d1_open 9063 / d_close 9114 / d1_close 8291 / d1_dip 5963（低吸成交率 65.4%）。每日事件数 最小 1 / 中位 5 / P95 13 / 最大 36。

**各变体窗口超额（事件组 − 同口径全池等权）：**

| 持有 N 日 | d1_open（基线） | d_close（尾盘） | d1_close | d1_dip（低吸） |
|---|---|---|---|---|
| 1 | +0.28% (t=3.11) | −0.75% (t=−11.8) | −0.76% (t=−14.6) | +0.24% (t=1.96) |
| 3 | −0.32% | −1.95% | −1.39% | −0.54% |
| 5 | −0.75% | −2.42% | −1.69% | −1.06% |
| 10 | −1.26% | −3.12% | −2.09% | −1.70% |
| 20 | −2.11% | −4.24% | −2.91% | −2.61% |

**低吸触及/未触及对照：**

| 持有 N 日 | 触及组超额 | 未触及组超额 |
|---|---|---|
| 1 | +0.34% | **+1.54%** |
| 3 | −0.44% | **+1.27%** |
| 5 | −0.93% | **+0.95%** |
| 10 | −1.61% | +0.75% |
| 20 | −2.52% | +0.03% |

**初步解读：**
1. 基线 d1_open 是四变体中最好的（n=1 唯一显著正超额）；尾盘抢跑全面最差。
2. 信号整体偏弱：除 n=1 外各变体超额全负且显著，「涨停次日倍量阴」更像弱势/出货模式而非买点。
3. 低吸对照结论最干净：未触及组（D+1 不回头）超额持续为正，触及组全负——低吸筛出弱势子集，便宜价不是免费午餐。
4. 信号扎堆度不高（P95 13 只/日），资金约束预警低。
