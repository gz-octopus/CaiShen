# Triage 标签

技能用五个规范 triage 角色说话。本文件把这些角色映射到本仓库 issue tracker 实际使用的 label 字符串。

| 技能中的角色 | 本仓库 label | 含义 |
| ------------ | ------------ | ---- |
| `needs-triage` | `needs-triage` | 维护者需要评估该 issue |
| `needs-info` | `needs-info` | 等待报告者提供更多信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整,可交给 AFK 代理 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会被行动 |

技能提到某个角色(如"打 AFK-ready 分流标签")时,使用表中对应的 label 字符串。

如果你们实际用别的词汇,直接改右侧一列即可。
